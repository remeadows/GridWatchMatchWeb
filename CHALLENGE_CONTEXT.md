# Challenge Context - Make A Game We Can Play

GridWatch Match Web is being built for the Community Dev Challenge: "Make a game we can play."

## Core Standard

The judging bar is simple and important: the game must be playable from a public link. Polish helps, but the primary requirement is that someone can open the URL and play without setup, secrets, or private access.

## Submission Requirements

- Public GitHub repo.
- Playable game link.
- Short description in the challenge thread.
- README must explain:
  - What was made.
  - How Codex helped.
  - How to play and controls.

## Hosting

Recommended hosting includes GitHub Pages, itch.io, or Vercel. This repo targets GitHub Pages.

## Deadline

The challenge image lists the deadline as June 21, 2026 at 11:59 PM PT. Discord may show the equivalent local time to each reader.

## Safety Rules

- Do not commit API keys, secrets, tokens, or `.env` files.
- OpenAI API usage can earn bonus points, but it is optional.
- This web repo should remain a static app unless a future secure backend is explicitly added.

## Product Implication

For this project, every implementation choice should prioritize a complete, reliable playable game:

- The board must feel responsive on pointer, touch, and mobile.
- All seven rows must be reachable and playable at common viewport sizes.
- Menus, level flow, fail/win modals, settings, persistence, and the store stub must work without backend services.
- README and deployment must be submission-ready before the challenge deadline.
