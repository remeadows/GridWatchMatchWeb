# GridWatch Match: Five New Villain Portraits

Prompts for ChatGPT. Roster confirmed by Russ on 2026-11-02. DREAD replaces AX-10M².

## How to use these

All paths below are inside the Google Drive folder `GridWatchArt`. A copy of this file sits in `GridWatchArt/4 - GridWatch Match/`.

1. Open one ChatGPT conversation and give it the five style images from `GridWatchArt/4 - GridWatch Match/`: `Vexis.png`, `Kron.png`, `Zero.png`, `AX10M.png`, `Aurora.png`.
2. For each villain, also give it the character reference listed under that villain's heading.
3. Paste the prompt. Keep all five in the same conversation so they match.
4. Each result must be a square PNG, 1024 × 1024 pixels, the same size as the five existing portraits.
5. Save each result to `GridWatchArt/4 - GridWatch Match/` under the file name shown.

## What makes the five existing portraits a set

- Square, head and shoulders, centred, facing the viewer dead on.
- Near-black background, with nothing behind the figure.
- A still, menacing face made of a dark material: polished skin, etched bronze, cracked stone, faceted helmet.
- One main glow colour per villain, with eyes as the brightest point.
- Thin circuit traces that follow the bones of the face.
- A soft highlight on the upper forehead and a thin rim of light, with the rest falling to black.
- Edges that break apart into small square pixels and sparks.

The game adds each villain's name, so the pictures carry no text. Each glow colour is the colour of that villain's sector, so no two sit side by side looking alike.
